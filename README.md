# shouldiworryhealth.com

The public sources site of the YouTube channel [Should I Worry?](https://www.youtube.com/@ShouldIWorry): every claim in each video, its timestamp, the study behind it and the strength of the evidence.

These pages are generated — do not edit them here. They are built by `sitegen.py` in the private pipeline repository (SebastianGreeff/shouldiworry-pipeline) from each episode's claim table and source list, and pushed here by the weekly run. General education, not medical advice.
